# Sass Scaffold

This a starter CSS scaffold to copy into a new project. It follows an ITCSS (Inverted Triangle CSS) architecture that helps keep CSS organized and scalable. It provides design tokens, a reset, a set of layout patterns and utility classes, organized into numbered layers. The components folder is empty as each project will determine what is needed. Most of the patterns and utilities are commented out on purpose: you turn on only what a project needs.
