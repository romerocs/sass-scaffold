# Sass Scaffold

This a starter CSS setup to copy into a new project. It follows an ITCSS (Inverted Triangle CSS) architecture that helps keep CSS organized and scalable. It provides design tokens, a reset, a set of layout patterns and utility classes, organized into numbered layers. The components folder is empty as each project will determine what is needed. Most of the patterns and utilities are commented out on purpose: you turn on only what a project needs, so a fresh build outputs a very small stylesheet of tokens, the reset and base element styles.

- CSS Custom Properties that distinquish between primitive and semantic variables.
- A modular scale that informs both font sizing and spacing.
- Layout patterns that are configurable and easy to override. 
- Clear, easy-to-follow class naming conventions for layout patterns, components and utilities.
